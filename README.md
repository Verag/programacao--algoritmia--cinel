### Programação e Algoritmia – Formação CINEL

Este repositório reúne os exercícios, projetos e apontamentos desenvolvidos durante a formação certificada Programação e Algoritmia do CINEL (125 horas).

Embora a minha experiência profissional esteja centrada na análise de dados com R, Python, SQL e Power BI, realizei esta formação para consolidar fundamentos de ciência da computação que me permitem escrever código mais robusto, eficiente e reutilizável.

#### Objetivos de aprendizagem

Ao longo da formação aprofundei conceitos como:

 - algoritmos e resolução estruturada de problemas;
 - programação orientada a objetos;
 - princípios de encapsulamento, herança e polimorfismo;
 - modularização e reutilização de código.

#### Conteúdo do repositório
 - Exercícios de algoritmia
 - Exercícios em C#
 - Exercícios em Java
 - Projetos desenvolvidos durante a formação
 - Apontamentos e materiais de apoio

#### Porque este repositório existe?

O meu foco profissional continua a ser Data Analytics e Data Engineering, principalmente utilizando R e Python.
Esta formação teve como objetivo reforçar os fundamentos de programação e programação orientada a objetos, competências que considero importantes para desenvolver software de maior qualidade e compreender melhor diferentes paradigmas de programação.
